# 定型メール下書き (mail-draft)

木の香の家の業務メールを、本人の文体で Gmail に**下書きとして**作成する。

## 絶対ルール(安全)

1. **送信しない。** 作るのは下書き(`mcp__Gmail__create_draft`)のみ。送信ボタンは本人が押す。
2. **添付ファイルは付けられない**ので、添付が必要なメールは本文冒頭に送信前チェック行(後述)を必ず入れ、本人が添付してから送る運用にする。
3. 宛先メールアドレスは、**過去スレッドで実際に使われたアドレス**を `search_threads` で確認してから設定する。見つからない場合は宛先を空にして、その旨を報告する。
4. 返信の場合は元スレッドを `get_thread` で読み、話の流れに合った内容にする。

## 手順

1. 用件を把握する。不足があれば1回だけ質問し、回答がなければ **[要記入: ◯◯]** のプレースホルダを入れて下書きを作る(止まらない)。
2. 相手と案件名で過去メールを検索し、宛先アドレス・先方の会社名・敬称・文脈を確認する。
3. `templates.md` から該当パターンを選び、本文を作成する。
4. `mcp__Gmail__create_draft` で下書きを作成し、件名・宛先・チェック行の内容をユーザーに報告する。

## 送信前チェック行(必須)

添付が必要な下書き、または顧客名・金額・日付を含む下書きは、**本文の一番上**に以下を入れる。本人が確認後にこのブロックを削除してから送信する。

```
━━ 送信前チェック(この3行を消してから送信) ━━
□ 添付: ◯◯(ファイル名まで確認)
□ 宛名/施主名の漢字: ◯◯様(例: 領家/猟家、前﨑/前崎の取り違え注意)
━━━━━━━━━━━━━━━━━━━━━━━━
```

## 文体ルール(実メールから抽出)

- 書き出し: 「いつもお世話になっております。株式会社 木の香の家の田中です。」(初回や久しぶりの相手はフルネーム「田中翔太です」)
- 社内宛は前置き最小限で用件のみ(「承知しました。」だけでも可)
- 結び: 「ご確認のほど、よろしくお願い申し上げます。」または「よろしくお願いいたします。」
- 署名(必ず末尾に付ける):

```
******************************
株式会社 木の香の家
田中翔太
〒488-0072
愛知県尾張旭市 新居町諏訪南1278-17
TEL:0561-52-1717
FAX:0561-52-2900
MAIL:s-tanaka@kinokanoie.com
******************************
```

- 過度な装飾・絵文字は使わない。1メール1用件。箇条書きは「・」を使う。

## パターン一覧

詳細な文例は同ディレクトリの `templates.md` を参照。

| # | パターン | 用途 |
|---|---|---|
| 1 | 書類送付 | 工程表・発注書・申請書・資金計画書などを送る |
| 2 | 取次転送 | 受け取った書類・情報を社内/他社に回す |
| 3 | 確認依頼 | 見積内容・仕様・設置可否などの確認を求める |
| 4 | 受領御礼 | 見積・提案・書類を受け取った旨の返信 |
| 5 | リマインド | 返答・書類待ちの相手への丁寧な催促 |
| 6 | 銀行報告 | 金融機関への契約報告・振込案内・書類送付 |
