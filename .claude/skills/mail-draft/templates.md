# メールテンプレート集(田中さん文体)

`{ }` は差し込み箇所。文面は実際の送信メールのトーンに合わせてある。

---

## 1. 書類送付

**件名**: `{施主名}様　{書類名}の送付`

```
{会社名}
{担当者名} 様

いつもお世話になっております。
株式会社 木の香の家の田中です。

{施主名}様邸の{書類名}を送付させていただきます。
ご確認のほど、よろしくお願い申し上げます。

(署名)
```

バリエーション:
- 遅れた場合: 冒頭に「大変お待たせいたしました。」
- 再送(誤り訂正)の場合: 「先ほどお送りした{書類名}ですが、誤ったファイルを添付しておりました。大変失礼いたしました。改めて正しいファイルを送付いたしますので、こちらでご確認いただけますでしょうか。」

## 2. 取次転送

**件名**: `Fwd: {元件名}` または `{施主名}様　情報共有`

社外へ:
```
{担当者名} 様

いつもお世話になっております。

{送り主}様より、{施主名}様の{書類・情報名}をいただきました。
内容の確認をお願いいたします。

よろしくお願いいたします。

(署名)
```

社内へ(最小限):
```
{用件を1〜2文}
{必要ならお願い事項}

(署名)
```

---

## 3. 確認依頼

**件名**: `Re: {元件名}` または `{施主名}様邸　{確認事項}の件`

```
{会社名}
{担当者名} 様

いつもお世話になっております。

{受け取った物への御礼を1文}

{確認してほしい内容}をご確認いただけますでしょうか。
・{確認ポイント1}
・{確認ポイント2}

お手数をおかけしますが、ご確認のほどよろしくお願いいたします。

(署名)
```

仕様変更を依頼する場合の中段例:
```
お見積りの内容について、以下の通り仕様変更の上、{書類名}の作成をお願いできますでしょうか。
・{変更点1}
・{変更点2}

今回の資料を改めてお客様へ提示し、最終確認が取れ次第、発注をさせていただきます。
```

## 4. 受領御礼

**件名**: `Re: {元件名}`

```
{担当者名} 様

いつもお世話になっております。
株式会社 木の香の家の田中です。

{書類名}をお送りいただき、誠にありがとうございます。
いただいた内容を社内で共有させていただきます。
内容を確認のうえ、改めてご連絡いたします。

引き続きよろしくお願い申し上げます。

(署名)
```

## 5. リマインド

**件名**: `Re: {元件名}` (元スレッドへの返信にする)

```
{会社名}
{担当者名} 様

いつもお世話になっております。
株式会社 木の香の家の田中です。

{MM月DD日}にご依頼しておりました{依頼内容}の件、
その後いかがでしょうか。

{期限がある場合: 「{期限日}までに{必要な理由}のため、}
お手数をおかけしますが、状況をお聞かせいただけますと幸いです。

よろしくお願いいたします。

(署名)
```

※角が立たないよう、依頼日を明記して「状況を聞く」形にする。催促の言葉(「早く」「至急」)は使わない。

## 6. 銀行報告・振込案内

**件名**: `{施主名}様　ご報告とご依頼`

```
{金融機関名}
{担当者名} 様

いつもお世話になっております。
木の香の家の田中翔太です。

{施主名}様の{契約・工事内容}につきまして、{報告内容}いたしましたのでご報告申し上げます。

つきましては、{送付書類}をお送りいたしますので、ご確認いただけますでしょうか。

なお、{上棟・完工などの予定}は{日付}を予定しており、
{振込等の依頼があれば記載}。

{期限が短い場合: 「お振込期限までの期間が短く、ご不便をおかけして誠に申し訳ございませんが、」}
何卒よろしくお願い申し上げます。

(署名)
```
