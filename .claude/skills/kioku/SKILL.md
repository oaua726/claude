## モードA: 記録する(既定・高頻度)

セッション終了を待たない。**きっかけが起きた瞬間に1行作る。**

### 1. 種別を決める

| きっかけ | 種別 | 重要度の目安 |
|---|---|---|
| 指示が出た / 変わった | 指示 | 中 |
| 選んだ・決めた・方針を変えた | 決定 | 恒久ルールなら高 |
| 訂正・指摘を受けた、ミスをした | ミス | 高 |
| 好み・文体・判断基準が表明された | 好み・文体 | 高 |
| 課題を解決した、手順が固まった | ナレッジ | 中 |
| 新しい事実が判明した | 事実 | 中 |
| 作業が一区切りした | 作業 | 低〜中 |

### 2. 書かないものを外す

**1往復1行ではない。** 挨拶・相槌・思考過程・未確定の推測・既記録の言い換えは書かない。
同じ話の続きは新しい行を作らず、`notion-update-page` で既存行の本文に追記する。

判断基準: 「3ヶ月後の自分がこれを読んで得をするか」。

### 3. 書く

`notion-create-pages` に `data_source_id` を指定して1行作る。

- **田中さんの指示・訂正・好みは原文のまま引用する**(要約も整形もしない)
- Claudeの作業内容は要約でよい
- 本文の型は `templates.md`
- 案件が特定できないものは `案件=全体`
- **選択肢に無い案件名・タグが必要なら、勝手に増やさず本人に確認する**

残す: 施主名・金額・業者名 / 書かない: 電話番号・住所・口座情報・パスワード・APIキー

### 4. 報告する

```
Notionに保存しました:
- [決定/高] ボノー様邸 — 見積の版管理は旧版をold/に退避する
- [ミス/高] 全体 — 宛先の敬称漏れ(再発防止チェック付き、未対策)
```

## モードB: 思い出す

「外部脳モードで」「前回の続き」「◯◯様邸の経緯教えて」等で起動。

**`notion-query-data-sources` で絞る。DB全件を取得しない。**

| 聞かれ方 | クエリ |
|---|---|
| セッション開始時の定型 | ①重要度=高の直近30件 ②種別=好み・文体の全件 ③種別=ミス&対応状況=未対策の全件 |
| 「前回の続き」 | 日時の直近20件 |
| 「◯◯様邸の経緯」 | 案件=◯◯様邸 の全件(日時降順) |
| 「何を決めたっけ」 | 種別=決定 かつ 重要度=高 |
| 「同じミスしてない?」 | 種別=ミス |

「前回の進捗 / 決定済みの前提 / 注意すべき過去のミス」の3点に整理して報告する。
該当記録がなければ「過去記録なし」と明示する。**憶測で埋めない。**

## モードC: 整理する

「整理して」で起動。

1. Inboxを読み、各行の分類先を判定する
2. **振り分け案を一覧で見せて確認を取る**
3. 承認後、セッション記録DBまたはKnowledgeへ転記する
4. Inbox側は消さず、転記済みの項目に「(YYYY-MM-DD → セッション記録へ)」を追記する

**Inboxの項目を削除しない。** 移動ではなく転記＋印付け。

### 棚卸し(「棚卸しして」)

- `種別=ミス` かつ `対応状況=未対策` を一覧化し、対策済みにできるものを確認する
- `重要度=高` の決定のうち、`docs/unyo-rule.md` に反映すべきものを提案する

```
Notionに接続できませんでした。記録内容を以下に出力します。手で貼り付けてください:
（プロパティ一覧＋本文全文）
```

記録内容そのものは必ず出力する。接続不可を理由に記憶を捨てない。
