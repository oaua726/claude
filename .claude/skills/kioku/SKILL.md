# 記憶 (kioku)

Notionの「外部脳」を外部記憶として読み書きする。分類ルールは `CLAUDE.md` が正。
構成とスマホ運用は `docs/gaibunou.md`。

このSkillは**追記専用**。ページの削除・全文置換・新規サブページ作成は行わない。

## モードA: 記録する(既定)

「記録して」「Notionに保存して」「覚えておいて」「今日の分まとめて」等で起動。

### 1. 分類する

**該当なしのカテゴリは書かない。** 空の見出しを作らないこと。

| 内容 | 書き込み先 |
|---|---|
| その日やったこと・決定・引き継ぎ | **Claude Log** |
| 課題/エラーを解決した、手順が固まった | **Knowledge** |
| ミスをした、指示と違って指摘・修正を受けた | **Mistakes** |
| まだ動いていない構想・ひらめき | **Ideas** |
| 進行中の取り組みの進捗・次アクション | **Projects** |
| 分類に迷う | **Inbox** |

書かないもの: 未確定の推測、単なる会話の要約、**パスワード・口座情報・APIキー・顧客の個人情報**。

### 2. 既存の中身を読む

`notion-fetch` で書き込み先ページを取得し、**既存の見出し形式と文体に合わせる**。
Knowledgeは同テーマの既存記述があれば、新規見出しを立てずに**そこへ追記して育てる**。

### 3. 書く

`notion-update-page` で**末尾に追記**する。既存本文を含めた全文置換はしない。

見出しは必ずこの形式(案件名を入れないと案件が混ざる):

```
## YYYY-MM-DD 案件名 — 要約
```

案件に紐づかないものは `全体` と書く。本文は `templates.md` の型に従う。

### 4. 報告する

どのページに何を書いたかを、必ずこの形式で報告する。

```
Notionに保存しました:
- Claude Log — 2026-09-19 ボノー様邸: 設備認定申請の期限確認、引き継ぎ2件
- Mistakes — 2026-09-19 全体: 宛先の敬称漏れ(再発防止チェック付き)
```

## モードB: 思い出す

「外部脳モードで」「前回の続き」「◯◯様邸の経緯教えて」等で起動。

1. `notion-fetch` で **Claude Log** を読む → 前回の進捗・決定・引き継ぎ
2. 案件が特定できるなら `notion-search` でその**案件名を横断検索**し、
   Knowledge / Projects / Claude Log の関連記述を読む
3. `notion-fetch` で **Mistakes** を読む → これからやる作業に関係する過去のミス
4. 「前回の進捗 / 決定済みの前提 / 注意すべき過去のミス」の3点に整理して報告する

該当記録がなければ「過去記録なし」と明示する。**憶測で埋めない。**

---

## モードC: 整理する

「整理して」で起動。Inboxを読み、各ページへ振り分ける。

1. `notion-fetch` でInboxを読む
2. 1件ずつ分類先を判定し、**振り分け案を一覧で見せて確認を取る**
3. 承認後、各ページへ追記する
4. Inbox側は消さず、振り分け済みの項目に「(YYYY-MM-DD → Knowledge へ)」を追記する

**Inboxの項目を削除しない。** 移動ではなく転記＋印付け。

## エラー時

Notionに繋がらない場合は**黙って進めない**。以下を伝える。

```
Notionに接続できませんでした。記録内容を以下に出力します。手で貼り付けてください:
（ここにMarkdown全文）
```

記録内容そのものは必ず出力する。接続不可を理由に記憶を捨てない。
