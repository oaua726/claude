# 記録テンプレート

`notion-update-page` で追記する本文の型。既存ページの文体に合わせ、**該当なしの項目は行ごと省く**。

---

## Claude Log(セッション記録・決定)

```markdown
## YYYY-MM-DD 案件名 — 要約

**話したこと**
- 

**決定・行動したこと**
- 決めたこと(なぜそう決めたか)
- 却下した案とその理由
- 恒久ルール / 今回だけの単発判断 のどちらか明記

**ミスと修正**
- なし(あれば Mistakes にも追記し、ここは1行で参照)

**次回への引き継ぎ**
- 前提:
- 未確定:
- 触ってはいけないもの:
```

---

## Knowledge(ナレッジ)

タイトルは「〜の原則」「〜のやり方」「〜とはなにか」形式。同テーマの既存記述があればそこへ追記。

```markdown
## テーマ名のやり方

**何が起きたか / 何をしたいか**
- 

**原因・前提**
- 

**手順(そのまま再現できる粒度で)**
1. 
2. 

**ハマりどころ**
- 

(YYYY-MM-DD 追記: )
```

---

## Mistakes(ミス)

謝罪文ではなく再発防止の材料として書く。過去の記述は消さない。

```markdown
## YYYY-MM-DD 案件名 — ミスの要約

**何をしたか(実際の誤った行動)**
- 

**本来どうすべきだったか(正しい対処法)**
- 

**なぜ間違えたか**
- 思い込み / 確認不足 / ルール未読 / 指示の読み違い のどれか

**再発防止チェック**
> 次に同じ状況になったら、自分にこう問う:「　」

**ルール側の修正**
- 必要 / 不要(必要なら何をどう直すか)
```

解決したら、その項目に `(YYYY-MM-DD 対策済み: 〜)` を追記する。**行を消さない。**

---

## Ideas / Projects / Inbox

```markdown
## YYYY-MM-DD 案件名 — 要約
- 
```

Inboxは1行でよい。振り分けたら `(YYYY-MM-DD → Knowledge へ)` を追記する。
