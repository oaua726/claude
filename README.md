# Retro-Futurist Sticker Generator

Generates a set of retro-futurist / synthwave-style sticker PNGs (planets, rockets, arcade badges, etc.) using Pillow.

## Setup

```bash
pip install -r requirements.txt
```

## Usage

```bash
python generate_stickers.py
```

Generated stickers are written to `output/` as 800x800 PNGs:

1. Neon Planet
2. Retro Rocket
3. Pixel Moon
4. Neon Starfield
5. Cyber Portal
6. Arcade Badge
7. Space Cat
8. Y2K Burst
