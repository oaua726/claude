# 外部脳(Notion)— 構成とスマホ運用

セッションを跨いで文脈・決定・ナレッジ・ミスを維持するための外部記憶。
保存先がNotionなので、**PC・iPad・スマホのどこからでも同じ記憶が使える**。

運用ルール本体は [CLAUDE.md](../CLAUDE.md)。ここは構成と、デバイス別の使い方。

---

## 1. なぜNotionなのか(ローカル保存にしなかった理由)

外部脳をローカル(Obsidian等)に置くと、**スマホのClaudeからは一切触れない**。
Claudeアプリからローカルのパソコンには接続できないため、記憶が使えるのは
「PCが起動していてClaude Codeを開いているとき」だけになる。

Notionに置けば、Claude側はコネクタ経由でどのデバイスからでも読み書きできる。
Notionアプリで人間が直接編集することもできる。

| | PCのClaude Code | スマホ/iPadのClaudeアプリ |
|---|---|---|
| 記憶の読み書き | ✅ | ✅ |
| `/kioku` などのSkill | ✅ | ❌(Claude Codeの機能) |
| 起動方法 | `/kioku` または自動 | **「外部脳モードで」と打つ** |

## 2. 構成

親ページ: **[外部脳](https://www.notion.so/377f6728bc1e8176b2cae224332401d5)**

### 記録の本体 — セッション記録DB

**[セッション記録](https://www.notion.so/1e2c4dae328f4bfbbda6b521172fb2b4)**

やり取りの記録はすべてここに**1件=1行**で入る。長いページへの追記はしない。

| プロパティ | 値 |
|---|---|
| 要約 | 一文で内容がわかる見出し |
| 日時 | YYYY-MM-DD |
| 種別 | 指示 / 決定 / ナレッジ / ミス / 作業 / 好み・文体 / 事実 |
| 案件 | 全体 / ボノー様邸 / 前﨑様邸 / 領家様邸 / 伊藤様邸 |
| 重要度 | 高(恒久ルール・重要な決定) / 中 / 低 |
| 対応状況 | 該当なし / 未対策 / 対策済み(ミス用) |
| タグ | 文体 / 判断基準 / 手順 / 期限 / 業者 / 書類 |

**なぜDBなのか**: 高頻度で詳細に記録すると、1枚の長いページでは数ヶ月で巨大化し、
読むたびに全文取得が必要になって記憶が使えなくなる。スマホでは特に重い。
DBなら種別・案件・重要度で絞り込めるので、何千件になっても想起が効く。

**案件はプロパティで絞る。** フィルタで `案件=ボノー様邸` にすれば経緯が時系列で並ぶ。

### 既存の7ページ(用途はそのまま)

| ページ | 用途 |
|---|---|
| Inbox | 未分類の一時置き場 |
| Ideas | まだ動いていない構想 |
| Knowledge | **DBの1行に収まらない**、繰り返し参照するまとまった知識 |
| Projects | 進行中の取り組み |
| Daily Log | その日の出来事(個人) |
| Claude Log | 2026-09-19以前の旧セッション記録。**追記しない** |
| Mistakes | 2026-09-19以前の旧ミス記録。**追記しない** |

Claude LogとMistakesは過去ログとして残す。新規の記録はセッション記録DBに一本化する。

## 3. スマホ・iPadでの使い方

Claudeアプリ(iPhone / iPad / claude.ai)を開いて、**最初にトリガー詞を打つ**。

| 打つ言葉 | Claudeの動作 |
|---|---|
| **外部脳モードで** | Claude Logを読んで文脈把握 → 自動保存・分類ルールを適用 |
| **前回の続き** | 同上 |
| **覚えておいて** | その情報を適切なページに即時書き込む |
| **整理して** | Inboxを読んで各ページに振り分ける(確認後) |

### 前提の確認

- claude.ai の設定 → コネクタ で **Notionが接続済み**であること(スマホアプリも同じ設定を共有する)
- 接続されていれば、スマホのClaudeがそのままNotionを読み書きできる

### 典型的な使い方

- **移動中に思いついた** → 「覚えておいて: ボノー様邸の追加照明、次の打合せで確認」
- **現場で前提を確認したい** → 「外部脳モードで。ボノー様邸の経緯教えて」
- **週末に棚卸し** → 「整理して」「棚卸しして」

### 記録の頻度と粒度

セッション終了時にまとめて書くのではなく、**きっかけが起きた瞬間に1行ずつ**書く。

| きっかけ | 種別 |
|---|---|
| 指示が出た / 変わった | 指示 |
| 決めた・方針を変えた | 決定 |
| 訂正・指摘を受けた | ミス |
| 好み・文体・判断基準を言った | 好み・文体 |
| 課題を解決した | ナレッジ |
| 新しい事実が判明した | 事実 |
| 作業が一区切りした | 作業 |

粒度は「**指示・訂正・好みは原文のまま、作業内容は要約**」。
「こうして」「それは違う」「この言い回しで」という発言は、要約せず原文で残す。
言い回しやニュアンスがそのまま文体・判断基準の資産になる。

ただし**1往復1行ではない**。挨拶・相槌・未確定の推測・既に書いた内容の言い換えは記録しない。
判断基準は「3ヶ月後の自分がこれを読んで得をするか」。

### スマホでできないこと

`/asa-brief` `/mail-draft` `/kigen` `/kioku` などのSkillは**Claude Codeの機能**なので、
スマホアプリでは使えない。スマホは**記憶の出し入れ**に使い、
メール下書き等の定型作業はPCのClaude Codeで行う。

## 4. PCでの使い方(Claude Code)

このリポジトリを開いてセッションを始めると `CLAUDE.md` が自動で読まれ、
セッション開始時の読み取りとセッション中の自動記録が効く。明示的に呼ぶ場合は `/kioku`。

---

## 5. ルールを変えるときの注意

運用ルールは**2箇所**にある。片方だけ直すとPCとスマホで挙動が食い違う。

| 場所 | 効く範囲 |
|---|---|
| `CLAUDE.md`(このリポジトリ) | PCのClaude Code |
| Notion「外部脳」ページの運用ガイド | スマホ・iPad・claude.aiのClaude |

**変更したら必ず両方を更新する。**

### 未対応(2026-09-19時点)

Notion「外部脳」ページの運用ガイドは**まだ更新していない**。古い内容(Claude Logに追記する前提)
のままなので、以下がスマホ側に反映されていない:

- セッション記録DBに書くというルール(→ スマホから記録すると旧Claude Logに書かれる)
- 種別・案件・重要度を付けるルール
- 「指示・訂正・好みは原文のまま」という粒度のルール
- 残してよい情報 / 書いてはいけない情報の線引き

暫定策: スマホから記録するときは「セッション記録DBに種別と案件を付けて記録して」と添える。
恒久対応するときは「外部脳ページの運用ガイドをセッション記録DBに合わせて更新して」と依頼する
(既存記述は消さず、追記または明示的な更新で)。

## 6. 書き込みの安全ルール(要約)

- **追記のみ**。既存記述の削除・全文置換はAIにさせない
- **新規サブページを勝手に作らせない**。構成変更は承認を得てから
- 訂正は旧記述を消さず「(YYYY-MM-DD 更新: 〜)」で履歴を残す
- 選択肢(案件・種別・タグ)を勝手に増やさせない。必要なら確認を取らせる
- ミスの記録は消さない。解決済みなら `対応状況=対策済み` に更新する

### 残してよい情報 / 書いてはいけない情報

| 残す | 書かない |
|---|---|
| 施主名、金額・見積・価格改定の内容、業者名・担当者名 | **電話番号・住所、口座情報、パスワード・APIキー** |

業務の記憶として機能させるため施主名と金額は残す。Notionは本人のアカウント内である前提。

---

## 7. つながらないとき

| 症状 | 対処 |
|---|---|
| スマホでNotionが読めない | claude.ai → 設定 → コネクタ でNotionの接続を確認・再接続 |
| Claude Codeで読めない | `/mcp` でNotionが connected か確認 |
| 保存したはずの内容がない | 保存先ページを直接開いて確認。Claudeは保存時に必ずページ名を報告する |

接続できないとき、Claudeは**記録内容をチャットに全文出力する**。手で貼り付ければ記憶は失われない。
