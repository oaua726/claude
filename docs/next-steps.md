## A. Notion案件データベース(業務OSの本丸)

### 目的
案件(施主)ごとの状態・期限・関係業者を一元管理し、/asa-brief の情報源にする。

### データベース設計
Notionの「Projects」配下に「案件管理」DBを新規作成(既存ページは変更しない)。

| プロパティ | 型 | 例 |
|---|---|---|
| 施主名 | タイトル | ボノー様邸 |
| ステータス | セレクト | 商談中/契約済/着工前/建築中/引渡済 |
| 上棟日 | 日付 | 2026-07-09 |
| 引渡予定 | 日付 | |
| 次のアクション | テキスト | 設備認定申請書を8/7までにTSMへ |
| 期限 | 日付 | 2026-08-07 |
| 関係業者 | マルチセレクト | TSM/インテルグロー/東邦ガス/豊田信金 |
| メモ | テキスト | 蓄電池見送り、先行配管のみ |

### 実装手順(次回セッションでの依頼文)
> docs/next-steps.md のA案を実装して。Notionに案件管理DBを作り、直近1ヶ月のGmailから案件(ボノー様、前﨑様、領家様、伊藤様など)を抽出して初期データを登録して。登録前に一覧を見せて確認を取ること。

### 運用
- 週1回 `/kigen` の結果をDBに反映(確認後)
- /asa-brief がこのDBを読むように SKILL.md に1段落追記する

## B. 週次レビューの自動実行(トリガー)

### 目的
毎週金曜17時に、無人で「今週の完了・停滞案件・来週の期限」レポートを生成する。

### 設計
- Claude Code Remote のスケジュールトリガー(cron: `0 17 * * 5`、JST換算に注意)で新規セッションを起動
- プロンプト: 「/asa-brief と /kigen を実行し、結果を docs/weekly/ にMarkdownで保存。メール送信・下書き作成・カレンダー変更は禁止」

### 安全設計(無人実行のため)
- 読み取り+リポジトリへのファイル保存のみ。Gmail下書きすら作らない
- 失敗時は何もせず終了(リトライで暴れない)

### 注意
- トリガー作成自体は数分で終わるが、**無人でAIが動く**ことへの同意を先に確認すること
- 実装依頼文: 「docs/next-steps.md のB案の週次レビュートリガーを作って」

## D. Google Chat連携(コネクタ待ち)

### 背景
2026-07-03時点、Anthropicのコネクタディレクトリ(claude.aiの接続設定・SearchMcpRegistry)に**Google Chat専用のMCPコネクタが存在しない**ことを確認済み。Google Calendar/Google Drive/Notionは接続・利用可能だが、Google Chatの読み取りに対応するツールはない(近いものとしてMicrosoft 365 Teams chat検索やGleanのchat機能はあるが、Google Chatそのものではない)。

このため `/asa-brief` にGoogle Chatのスペース・DMを自動で読ませることは、現時点では実装不可能。コネクタが提供され次第、以下の仕様ですぐ着手する。

### 目的
Gmail・カレンダーに加えて、社内のGoogle Chat(スペース・DM)上でのやり取り — 特に上司(𠮷田さん・栁原さん等)からの口頭・チャットでの指示や、現場からの即時連絡 — を朝ブリーフィングに含める。実メールにも「田中くんの方で電話して対応お願いします」のような、Chat/口頭指示がメールに転記される形で残っている実例があり、Chat側で直接発生する依頼はメールブリーフィングだけでは拾えていない。

### コネクタが使えるようになった場合の実装手順
1. `ListConnectors` / `SearchMcpRegistry` で "Google Chat" を確認し、接続する
2. 利用可能になるツール(スペース一覧・メッセージ検索など、実際のツール名は接続後に確認)を使い、`.claude/skills/asa-brief/SKILL.md` の「2. Gmailを調査」の後に「3. Google Chatを調査(直近3日分・自分宛のメンション/DM/重要スペース)」のステップを追加
3. 出力形式の「🔴 要返信」セクションに、メール由来かChat由来かのタグ(例: 📧/💬)を付けて区別する
4. `/kigen`(期限抽出)にもChatメッセージを情報源として追加できるか検討(Chatは期限の言及が少ない想定のため優先度は低)

### 実装依頼文(コネクタ接続後)
> Google Chatコネクタが使えるようになったので、docs/next-steps.md のD案に沿って asa-brief にGoogle Chat連携を追加して。

### それまでの代替運用(今すぐできる簡易統合)
コネクタなしでも、以下の運用で近い効果は得られる:
- 重要なChatメッセージは本文をコピーして「このChatの内容も踏まえてブリーフィングして: (貼り付け)」と渡す
- `/asa-brief` は元々「情報が取得できないツールがあった場合は、その旨を明記して残りの情報でブリーフィングを完成させる」設計のため、貼り付けられたChatテキストをその場で要返信・期限・待ちに分類して統合できる(SKILL.mdの変更は不要)
