# 書類チェックリスト集

実際に起きたミス(誤ファイル添付→再送 / 銀行支店名の記入漏れ→差し戻し / 施主名の誤記)を仕組みで防ぐためのチェックリスト。
印刷して使うか、Claudeに「◯◯のチェックリストで確認して」と渡してAIチェックにも使える。

---

## 1. メール送信前チェック(全メール共通・4点)

- [ ] **宛先**: アドレスは過去のやり取りと同じか。社外秘の内容をCCに入れていないか
- [ ] **添付**: ファイルを開いて中身を目視したか(ファイル名だけで判断しない)。**施主名がファイル内容と一致しているか**
- [ ] **固有名詞**: 施主名の漢字(例: 領家/猟家、前﨑/前崎)、担当者名、会社名
- [ ] **数字**: 金額・日付・期限・型番・色(例: ノーブルグレー/ピュアホワイト)

> 誤送信・誤添付は「再送のお詫びメール」1通で済まず、信用コストがかかる。30秒のチェックが最も安い保険。

---

## 2. 太陽光・設備認定申請(TSM関係)

提出前:
- [ ] 設備認定申請書の**全欄**が埋まっているか — 特に**売電収入の振込先口座(銀行名・支店名・口座番号)**
- [ ] 施主名の漢字・住所が契約書と一致しているか
- [ ] 電気図面・地図など、先方から依頼された優先順位①の書類が揃っているか
- [ ] 提出期限をカレンダーに登録したか(例: 8/7期限 → 8/4にリマインド)

送付時:
- [ ] 送付先(工務 koumu@ / 営業 sales@)を間違えていないか
- [ ] メール本文に「何を・何通」送ったか明記したか

---

## 3. 契約変更・中間金・銀行連絡

- [ ] 変更契約書の締結が完了しているか(発注書は契約完了後に送る)
- [ ] 資金計画書は**最新版**か(旧版ファイルとの取り違え注意)
- [ ] 振込案内: 金額・期日・振込先の3点を本文または添付に明記したか
- [ ] 期日までの期間が短い場合、お詫びの一文を入れたか
- [ ] 銀行担当者へ上棟日・完工日などのスケジュールを伝えたか

---

## 4. 上棟前の書類・段取り

- [ ] 工程表を関係業者(太陽光・設備・銀行)に送付済みか
- [ ] 発注書の送付(契約完了が前提)
- [ ] 上棟日が関係者全員に共有されているか
- [ ] タイトなスケジュールの場合「間に合わない等あればご相談ください」の一文を入れたか

---

## 5. 見積確認(受け取った見積のチェック)

- [ ] **施主名**が正しいか(先方の誤記もチェックして指摘する)
- [ ] **色・仕様**が打合せ内容と一致しているか(例: 電話で「グレー」と伝えた→見積が「ピュアホワイト」だった事例)
- [ ] 型番・数量・排水芯などの寸法条件
- [ ] **価格改定の予告**がないか(「8月より価格改定」→発注時期の判断材料としてメモ・共有)
- [ ] 有効期限

---

## 6. モデルハウス見学・顧客対応の引き継ぎ

- [ ] 顧客名・連絡先・希望日時を確認したか
- [ ] 顧客の関心事(例: 外構・収納の悩み、Instagram経由)を引き継ぎメモに書いたか
- [ ] 対応期限: 割り振られたら**当日中に一次連絡**(電話 or メール)
- [ ] 日程確定後、カレンダーに登録+社内共有したか
