# Obsidian Vault(外部脳)

このフォルダがそのまま Obsidian の Vault。Claude のセッションを跨いで文脈とナレッジを保持するための保管場所。

## ローカルでの開き方

Obsidian → 「フォルダをVaultとして開く」 → このリポジトリの `obsidian/` を選ぶ。
（リポジトリ全体ではなく `obsidian/` を指定する。`docs/` や `output/` はVaultに含めない）

## フォルダの使い分け

| フォルダ | 入れるもの | ファイル名 |
|---|---|---|
| `Daily/` | その日の作業内容・引き継ぎ事項 | `2026-09-19.md`(1日1ファイル) |
| `Decision/` | 判断・決定と、その理由やルール | `2026-09-19_見積の突合はAIに任せる.md` |
| `Knowledge/` | 解決した課題、エラー対処法、設定手順 | `TSM設備認定申請の出し方.md`(日付なし・テーマ名) |
| `Mistakes/` | やらかした内容と正しい対処法 | `2026-09-19_旧版の資金計画書を添付.md` |

各フォルダの `_template.md` が書式。新規ノートはテンプレをコピーして書く。`_` 始まりのファイルは記録本体ではないので読み込み対象から除外してよい。

## 書くときの約束

- **日付は `YYYY-MM-DD`**(ファイル名・frontmatter とも)。`2026/9/19` のような表記は混ぜない
- **固有名詞は契約書表記に統一**(領家/猟家、前﨑/前崎の揺れを持ち込まない → `docs/unyo-rule.md`)
- **パスワード・口座番号・個人の連絡先は書かない**。「振込先は資金計画書v2に記載」のように参照で残す
- ノート同士は `[[2026-09-19]]` の形式でリンクする。Daily を起点に Decision / Mistakes へ辿れる状態を保つ

## 運用ルール本体

読み取り・書き込み・ミス管理の手順はリポジトリ直下の `CLAUDE.md` にある。Claude Code はセッション開始時にそれを自動で読む。
