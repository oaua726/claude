## 進行中の案件(Dataview)

```dataview
TABLE WITHOUT ID
  file.link AS 案件,
  status AS 状況,
  引渡予定 AS 引渡予定,
  dateformat(file.mtime, "MM-dd") AS 最終更新
FROM #type/案件
WHERE status != "完了" AND status != "失注"
SORT 引渡予定 ASC
```

> [!note] Dataviewプラグインを入れていない場合
> 上のブロックはただのコードとして表示されます。手動の一覧は [[02_案件/_案件一覧]] にあります。
> 入れ方: 設定 → コミュニティプラグイン → 閲覧 → "Dataview" → インストール → 有効化

## 直近7日で触ったノート

```dataview
LIST
WHERE file.mtime >= date(today) - dur(7 days) AND file.name != "ホーム"
SORT file.mtime DESC
LIMIT 15
```
