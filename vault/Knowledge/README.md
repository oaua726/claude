# Knowledge（ナレッジ）

プロジェクトで得た知見や、具体的な問題の対処法を蓄積するフォルダ。
一度調べたこと・解決したことを二度調べ直さないための「辞書」。

## 記入ルール

- 新しい知見（ツールの使い方、ハマりどころの回避法、環境固有の事情など）を得たら1ノート作成する
- ファイル名: `テーマの短い要約.md`（例: `Pillowでの透過PNG出力.md`）
- 書式は [[_template]] に従う
- 同じテーマの知見が増えたら、新規ノートを作らず既存ノートに追記してよい

- セッション開始時、今回のタスクに関連しそうなノートを確認すること
- 問題解決に時間がかかったこと・調査して分かったことは、解決した時点でここに記録すること
