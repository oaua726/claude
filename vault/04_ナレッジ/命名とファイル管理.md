# 命名とファイル管理

## 実ファイル(Drive/PC)

形式: `YYYYMMDD_施主名_書類種別_版.拡張子`
例: `20260629_サンプル様_資金計画書_v2.pdf`

- 日付は**最終更新日**。更新したら日付を変えて別名保存(上書きしない)
- 旧版は案件フォルダ内の `old/` へ。**送付対象フォルダに版違いを2つ置かない**(誤添付の根本原因)
- 施主名の漢字は契約書表記に統一

```
案件/{施主名}様邸/
  01_契約/  02_設計/  03_申請/  04_工程/  05_引継メモ/  old/
```

## Vault(このObsidian)

| 種類 | ノート名 | 置き場所 |
|---|---|---|
| 案件ハブ | `{施主名}様邸` | `02_案件/{施主名}様邸/` |
| 打合せ | `YYYY-MM-DD_打合せ` | `02_案件/{施主名}様邸/ログ/` |
| 取引先 | 会社名 | `03_取引先/` |
| ナレッジ | 内容がわかる名詞 | `04_ナレッジ/` |
| 日次 | `YYYY-MM-DD` | `01_Daily/` |

## 役割分担(どこに何を置くか)

| 置き場 | 役割 |
|---|---|
| Gmail | 事実の原本(やり取りそのもの) |
| Drive / PC | 書類の原本 |
| Googleカレンダー | 確定した予定・期限のアラーム |
| **Obsidian(ここ)** | **判断・経緯・仕様・ナレッジ = 外部脳** |
| Notion | 社内・チームで共有するもの |

迷ったときの基準: **検索して出てくればGmail/Driveで十分。思い出す必要があるものはObsidian。**
