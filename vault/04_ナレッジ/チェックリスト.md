# チェックリスト

> 正本はリポジトリの `docs/checklists.md`。ここは現場で開く用の写し。
> Claudeに「見積チェックリストでこのPDFを確認して」と渡すAIチェックにも使える。

## メール送信前(全メール共通・4点)

- [ ] **宛先**: 過去のやり取りと同じアドレスか。社外秘をCCに入れていないか
- [ ] **添付**: 開いて中身を目視したか。施主名がファイル内容と一致しているか
- [ ] **固有名詞**: 施主名の漢字、担当者名、会社名
- [ ] **数字**: 金額・日付・期限・型番・色

## 太陽光・設備認定申請

- [ ] 申請書の全欄(特に**売電収入の振込先: 銀行名・支店名・口座番号**)
- [ ] 施主名の漢字・住所が契約書と一致
- [ ] 依頼された優先順位①の書類(電気図面・地図など)が揃っている
- [ ] 提出期限をカレンダー登録 + 3日前リマインド
- [ ] 送付先(工務/営業)を間違えていない
- [ ] 本文に「何を・何通」送ったか明記

## 契約変更・中間金・銀行連絡

- [ ] 変更契約の締結が完了しているか(発注書は締結後)
- [ ] 資金計画書は最新版か(旧版との取り違え注意)
- [ ] 振込案内に 金額・期日・振込先 の3点
- [ ] 期日が近い場合はお詫びの一文
- [ ] 上棟日・完工日など銀行担当者への共有

## 上棟前

- [ ] 工程表を関係業者(太陽光・設備・銀行)へ送付
- [ ] 発注書の送付(契約完了が前提)
- [ ] 上棟日が全員に共有されている
- [ ] タイトな場合「間に合わない等あればご相談ください」の一文

## 受け取った見積のチェック

- [ ] 施主名(先方の誤記も指摘する)
- [ ] 色・仕様が打合せ内容と一致(→ 案件ノートの仕様表と突合)
- [ ] 型番・数量・排水芯などの寸法条件
- [ ] 価格改定の予告 → `#期限/価格改定` で記録
- [ ] 有効期限

## 顧客対応の引き継ぎ

- [ ] 顧客名・連絡先・希望日時
- [ ] 関心事(外構・収納・Instagram経由など)を引き継ぎメモに
- [ ] 当日中に一次連絡
- [ ] 日程確定後にカレンダー登録+社内共有
