# 用語集

言い間違い・書き間違いが事故になる語をここに集める。

| 用語 | 意味・正しい表記 | 注意 |
|---|---|---|
| 設備認定申請 | 太陽光の売電に必要な申請 | 振込先口座欄の記入漏れが差し戻しの定番 |
| 中間金 | 工事途中で受け取る支払い | 案内は金額・期日・振込先の3点 |
| 上棟 | 棟上げ。関係業者への工程共有の節目 | 日程は全員に共有 |
| 排水芯 | 洗面・便器の排水位置(mm) | 見積で見落としやすい寸法条件 |
| ノーブルグレー / ピュアホワイト | 外壁・設備の色名 | 電話で伝えた色は必ず案件ノートの仕様表へ |
