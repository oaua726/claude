# 定型文集

## 6パターン

| パターン | 使う場面 | 要点 |
|---|---|---|
| 書類送付 | 見積・工程表・申請書を送る | 何を・何通・期限を本文に明記 |
| 取次転送 | 社内・業者へ引き継ぐ | 誰に何をしてほしいかを冒頭1行で |
| 確認依頼 | 仕様・金額の食い違い | 打合せ日と「こちらの認識」を併記 |
| 御礼 | 対応後 | 短く。次の一手があれば添える |
| リマインド | 期限前 | 責めない書き方 + 期日を再掲 |
| 銀行報告 | 契約・中間金 | 金額・期日・振込先の3点セット |

## 言い回しのストック

- 期日がタイトなとき: 「お忙しいところ恐れ入りますが、◯月◯日までにご対応いただけますと幸いです。間に合わない等ございましたらご相談ください。」
- 認識合わせ: 「◯月◯日のお打合せでは◯◯で伺っておりましたが、念のためご確認をお願いいたします。」
- 誤りの指摘(相手のミス): 「恐れ入りますが、施主名が『◯◯』となっておりました。ご確認いただけますでしょうか。」
