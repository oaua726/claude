# 外部脳 Vault(Obsidian)

木の香の家・田中さん用の外部脳。**仕事(案件・期限・取引先・ナレッジ)と個人(アイデア・学び・副業)を1つのVaultに**入れる構成。
このフォルダ(`vault/`)を**そのままObsidianで開けば使える**。

## 使い始め(5分)

1. Obsidianを起動 → 「フォルダを保管庫として開く」→ この `vault` フォルダを選ぶ
2. 開いたら [[ホーム]](`ホーム.md`)を開いてブックマーク(`Ctrl/Cmd + P` → 「ブックマークに追加」)
3. 設定 → コミュニティプラグイン → 制限モードをオフ → 「Dataview」をインストールして有効化
   - 入れなくても使えるが、[[期限ダッシュボード]] と各一覧が自動更新になるので推奨
4. `Ctrl/Cmd + P` → 「デイリーノートを開く」で今日のノートができる(テンプレ適用済み)
5. あとは**迷ったら `00_Inbox` に放り込む**だけ。分類は金曜の週次レビューでまとめて

> 設定(添付先・デイリーノート・テンプレート)は `.obsidian/` に同梱済み。初回起動時に読み込まれる。

## フォルダ構成

| フォルダ | 入れるもの |
|---|---|
| `00_Inbox` | 未分類。とりあえずここ。週1で空にする |
| `01_Daily` | デイリーノート(日々の打合せ・電話ログ、気づき) |
| `02_案件` | 施主ごとの案件ノート + 打合せログ |
| `03_取引先` | 業者・銀行・社内の担当者、送付先の使い分け、クセ |
| `04_ナレッジ` | チェックリスト・定型文・手順・用語・命名規則 |
| `05_個人` | アイデア / 学び / 副業 |
| `06_レビュー` | 週次・月次レビュー |
| `90_Templates` | 各種テンプレート |
| `91_Attachments` | 画像などの添付(業務書類の原本は入れない) |
| `99_Archive` | 完了・不要になったノートの退避先 |

## 3つのルール

1. **入れるのは判断と経緯**。書類の原本はDrive/PCに、予定はカレンダーに。Obsidianは「思い出す必要があるもの」だけ
2. **口頭で受けた依頼は必ず1行残す**(デイリーノート)。記録に残らない依頼が一番あとで効く
3. **仕様は色・型番まで書く**(案件ノートの仕様表)。「グレーと伝えた/ホワイトで見積が来た」を防ぐ

## 期限の書き方(重要)

どのノートでもいいので、チェックボックスに `[due:: YYYY-MM-DD]` を付ける:

```markdown
- [ ] 設備認定申請書を提出 [due:: 2026-10-07] [案件:: [[サンプル様邸]]] #期限/申請
```

これだけで [[期限ダッシュボード]] に自動で集まる(Dataview有効時)。
元ネタはGmail。Claude Codeで `/kigen` を実行 → 出てきた期限をこの書式で書く。

## Claude Codeとの連携

| コマンド | 使いどころ | Vault側での受け |
|---|---|---|
| `/asa-brief` | 毎朝 | デイリーノートに貼る |
| `/kigen` | 金曜の週次レビュー | 期限を `[due:: ]` 付きで案件ノートへ |
| `/mail-draft` | 定型メール | 送った事実を案件ノートの経緯ログへ1行 |

安全ルール(送信は必ず本人、既存データの変更・削除はAIにさせない)は [[04_ナレッジ/AIに任せる範囲]] 参照。

## 同期について

- **このリポジトリはGitで同期される**。PC間で使うならリポジトリごとclone/pullする
- スマホからも使いたい場合は Obsidian Sync か iCloud/Dropbox 等に `vault` を置く方法もある(その場合Gitと二重管理にしない)
- `.obsidian/workspace.json` など端末固有の状態は `.gitignore` 済み
- **顧客の個人情報(住所・連絡先・口座)は書かない**。案件ノートには「Driveのどのファイルにあるか」だけ書く
