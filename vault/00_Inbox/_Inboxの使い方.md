# 📥 Inboxの使い方

**ルール1つだけ: 迷ったらここに入れる。分類は後回し。**

- 思いついたこと、電話で言われたこと、あとで調べること → 新規ノート(テンプレ: [[90_Templates/クイックメモ]])
- 新規ノートのデフォルト保存先はこのフォルダに設定済み
- 週次レビュー(金曜10分)で空にする

## 振り分け先の判断

| 中身 | 行き先 |
|---|---|
| 特定の施主・案件の話 | [[02_案件/_案件一覧]] の該当案件ノート |
| 業者・銀行・担当者のクセや連絡先 | [[03_取引先/_取引先一覧]] |
| 手順・定型文・チェック項目 | [[04_ナレッジ/_ナレッジ目次]] |
| 期限がある | タスク化して `[due:: YYYY-MM-DD]` を付ける → [[期限ダッシュボード]] |
| 個人の思いつき | [[05_個人/アイデア/_アイデア箱]] |
| もう不要 | 削除(残さない勇気) |

## 溜まっているもの
