# 🤝 取引先一覧

「この会社、前どうだったっけ」を1ノートで思い出すための場所。
新規は [[90_Templates/取引先ノート]] から作る。ファイル名は会社名(担当者名ではない)。

## 一覧(Dataview)

```dataview
TABLE WITHOUT ID file.link AS 取引先, 分類, join(担当者, ", ") AS 担当者
FROM #type/取引先
SORT 分類 ASC, file.name ASC
```

## 手動一覧

| 取引先 | 分類 | 担当 | 注意点 |
|---|---|---|---|
|  | 業者 |  | 送付先(工務/営業)の使い分けに注意 |
|  | 銀行 |  | 中間金の案内は期日と金額と振込先の3点セット |

## よくある事故と対策

- **送付先の取り違え**(工務 koumu@ / 営業 sales@)→ 取引先ノートの「送付先の使い分け」を見てから送る
- **価格改定の見落とし**→ 見積に改定予告があれば取引先ノートと [[期限ダッシュボード]] の両方に `#期限/価格改定` で記録
