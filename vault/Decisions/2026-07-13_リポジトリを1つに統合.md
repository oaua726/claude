# リポジトリを1つに統合

- **日付**: 2026-07-13
- **タグ**: #decision

## 課題・きっかけ

一時は保管庫を専用リポジトリ（oaua726/obsidian-vault）に分離する方針にしたが、リポジトリが2つあって紛らわしいとユーザーから指摘。1つに統合したい。

## 検討した選択肢

1. `oaua726/claude` に一本化し、`obsidian-vault` は削除する
2. `obsidian-vault` に一本化し、`oaua726/claude` を削除する

## 決定

**`oaua726/claude` の1リポジトリに一本化する。** 保管庫は `vault/` サブフォルダとして維持。空だった `obsidian-vault` はユーザーが GitHub の Web 画面から削除する。

## 理由・判断基準

- 外部記憶の中身（ノート・CLAUDE.md・.mcp.json・docs/SETUP.md）はすべて既に `oaua726/claude` にあり、追加作業なしで完結している
- このセッションのアクセス権が `oaua726/claude` に限定されており、`obsidian-vault` へのプッシュは権限エラーで通らなかった。確実に維持・更新できる方を残す
- 前回の「専用リポジトリに分離」（[[Decisions/2026-07-13_保管庫を専用リポジトリに分離]]）はこの決定で撤回する
- 保管庫は `vault/` サブフォルダのまま。Obsidian では `vault/` を保管庫として開く（ステッカー生成スクリプトとは無関係、CLAUDE.md に明記済み）
