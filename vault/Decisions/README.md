# Decisions（決定事項）

どのような時にどのような判断をしたか、ユーザー自身のルールや判断基準を記録するフォルダ。
Claude が「この人ならこう判断するはず」と意図を汲み取れるようになるための土台。

## 記入ルール

- ユーザーと方針・ルール・好みを決めたら1ノート作成する（例: コーディング規約、コミットの粒度、使うライブラリの選定基準）
- ファイル名: `YYYY-MM-DD_決定の短い要約.md`（例: `2026-07-04_Vaultはリポジトリ内に置く.md`）
- 書式は [[_template]] に従う
- 決定が覆ったら古いノートを消さず、新しいノートから旧ノートへリンクして経緯を残す

## Claude への指示

- セッション開始時、今回のタスクに関連する決定事項を確認し、それに従うこと
- 判断に迷ったら、まずここに過去の類似判断がないか探すこと
- ユーザーが何かを決めた・好みを示したら、その場でここに記録すること
