# Vault 配置と接続方式

- **日付**: 2026-07-04
- **タグ**: #decision

## 課題・きっかけ

外部記憶システム構築にあたり、(1) Obsidian 保管庫（Vault）の置き場所、(2) Claude と Obsidian を繋ぐ方式を決める必要があった。

## 検討した選択肢

1. **Vault**: リポジトリ内に作成 ／ 外部パスを想定してテンプレートのみ置く
2. **接続方式**: ファイル直接アクセスのみ ／ mcp-obsidian（REST API） ／ filesystem MCP サーバー ／ 両対応

## 決定

1. **Vault はこのリポジトリ内の `vault/` に作成**する
2. **REST API（mcp-obsidian）を優先し、使えなければファイル直接アクセスにフォールバック**する

## 理由・判断基準

- リポジトリ内配置なら Git で記憶自体をバージョン管理・同期でき、セットアップも簡単
- REST API は Obsidian 固有機能（検索など）が使えるが、Obsidian 起動中しか繋がらない。ノートはただの Markdown なので、標準ツールでの直接読み書きを常時使える保険とする（`CLAUDE.md` に明文化済み）
