# Mistakes（ミス）

Claude が行ったミスと、その修正方法を記録するフォルダ。
**毎セッション開始時に全件参照する**ことで、同じミスを繰り返さないようにし、AI の精度を向上させる。

## 記入ルール

- ユーザーからミスを指摘されたら（または自分でミスに気づいて修正したら）、1件につき1ノートを作成する
- ファイル名: `YYYY-MM-DD_ミスの短い要約.md`（例: `2026-07-04_テスト実行せずにコミット.md`）
- 書式は [[_template]] に従う
- 「何をやったか」だけでなく「**次からどうするか**」を必ず書く — ここが再発防止の核

## Claude への指示

- セッション開始時、このフォルダのノートすべてに目を通すこと
- 記録済みのミスと同じパターンを踏みそうになったら、実行前に立ち止まって回避すること
