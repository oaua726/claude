# HOME — 外部記憶（外部脳）の入口

この Vault は、Claude Code の「外部記憶（外部脳）」として機能します。
Claude はセッション開始時にここを読みに来て過去の経緯を思い出し、作業中に得たものをここへ書き残します。

## フォルダ構成

| フォルダ | 役割 |
| --- | --- |
| [[Mistakes/README\|Mistakes（ミス）]] | Claude が行ったミスと修正方法の記録。毎セッション参照して同じミスを繰り返さない |
| [[Knowledge/README\|Knowledge（ナレッジ）]] | プロジェクトで得た知見・問題の対処法の蓄積 |
| [[Decisions/README\|Decisions（決定事項）]] | どんな時にどう判断したか。ルールや判断基準の記録 |
| [[Daily/README\|Daily（日次記録）]] | その日の作業内容。翌日「昨日の続き」をスムーズに再開するため |

## 運用ルール（要約）

- **読み取り**: 新しいセッションを開始したら、作業に入る前に必ずこの Vault を確認する
  - `Daily/` の最新ノート → 前回の続きを把握
  - `Mistakes/` → 全件に目を通す
  - `Decisions/`・`Knowledge/` → タスクに関連するもの
- **書き込み**: ミスの修正・新しい知見・決定事項・日次の作業内容を、対応するフォルダに記録する
- 詳細なルールはリポジトリルートの `CLAUDE.md` に定義されている

## 育て方

最初から完璧なルールは不要。使いながら「これは覚えておいて」「セッション開始時にここを確認して」と Claude に直接伝えて、徐々にルールを肉付けしていく。
