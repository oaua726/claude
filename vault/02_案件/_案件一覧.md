# 🏡 案件一覧

新規案件の作り方:
1. このフォルダに `{施主名}様邸` フォルダを作る
2. その中に `{施主名}様邸.md` を作り、テンプレ [[90_Templates/案件ノート]] を挿入
3. 打合せのたびに `ログ/` に [[90_Templates/打合せメモ]] で1ノート

```
02_案件/
  サンプル様邸/
    サンプル様邸.md        ← ハブ(仕様・関係者・期限)
    ログ/
      2026-09-12_打合せ.md
```

> 実ファイル(図面・見積・契約書)はVaultに入れない。Drive/PCの案件フォルダに `YYYYMMDD_施主名_書類種別_版.拡張子` で置く。
> 詳細 → [[04_ナレッジ/命名とファイル管理]]

## 進行中

```dataview
TABLE WITHOUT ID
  file.link AS 案件,
  status AS 状況,
  上棟予定, 引渡予定, 銀行
FROM #type/案件
WHERE status = "進行中"
SORT 引渡予定 ASC
```

## 保留・完了

```dataview
TABLE WITHOUT ID file.link AS 案件, status AS 状況, dateformat(file.mtime, "yyyy-MM-dd") AS 最終更新
FROM #type/案件
WHERE status != "進行中"
SORT file.mtime DESC
```
