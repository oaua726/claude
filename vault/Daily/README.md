# Daily（日次記録）

その日の作業内容を記録するフォルダ。
翌日のセッションで Claude がまずここを読み、「昨日の続き」をスムーズに再開できるようにする。

## 記入ルール

- 1日1ファイル。ファイル名: `YYYY-MM-DD.md`（例: `2026-07-04.md`）
- 書式は [[_template]] に従う
- 同じ日に複数セッションがあれば、新規作成せず同じファイルに追記する

## Claude への指示

- セッション開始時、このフォルダの**最新のノート**を必ず読み、前回の続き・未完了タスクを把握すること
- セッション終了時・作業の区切りごとに、今日の日付のノートへ「やったこと」「未完了」「次にやること」を書き込むこと
