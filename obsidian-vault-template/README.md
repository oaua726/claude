# 業務メモ Vault

Claude Codeの外部記憶(外部脳)として使うVault。
書き込みルールは業務リポジトリの `CLAUDE.md` が正。ここは構成の説明だけ。

## フォルダ

| フォルダ | 入れるもの | ファイル名 |
|---|---|---|
| `Daily/` | その日の作業記録・引き継ぎ | `YYYY-MM-DD.md` |
| `Decision/` | 判断・決定とその理由(1決定1ファイル) | `YYYYMMDD_件名.md` |
| `Knowledge/` | 解決した課題・手順・設定(テーマ単位で育てる) | `テーマ名.md` |
| `Mistakes/` | ミスと正しい対処法 | `YYYYMMDD_ミスの要約.md` |
| `_templates/` | 上記4種のテンプレート(カテゴリではない) | — |

案件別フォルダは作らない。案件はフロントマターの `project:` とタグ `案件/◯◯様邸` で区別する。

## 手で触るとき

- 書き足す・直す・消すのは自由。**記憶が見えて直せるのがこの方式の利点**
- ただし `Mistakes/` は消さない(再発防止の材料として残す)
- 古くなった記述は消さず「(YYYY-MM-DD 更新: 〜)」を添えて履歴を残す

## 秘匿情報

パスワード・口座番号・APIキーは**このVaultに書かない**。
