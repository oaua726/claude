# POLYRUN

ブラウザで即遊べるローポリ無限ランナー。`index.html` 1ファイル完結（外部依存は three.js r128 の CDN のみ）。

## 遊び方

`games/polyrun/index.html` をブラウザで開くだけ。インストール不要、サーバー不要。

| 操作 | キーボード | タッチ |
|---|---|---|
| レーン移動 | ← → / A D | 左右スワイプ |
| ジャンプ | SPACE / ↑ / W | タップ・上スワイプ |
| スライド | ↓ / S | 下スワイプ |
| サウンド ON / OFF | M | 右下の SOUND ボタン（全画面で常時表示）|

## ルール

- 3レーンの道を自動で前進する。障害物に1回でも当たったら終了。
- **赤い壁 → ジャンプ / 青いバー → スライド / 紫の柱 → レーン移動**。色で回避方法が決まる。
- クリスタルとニアミスでコンボが伸びる（最大 x10、3秒で切れる）。
- スコア = 距離(1/m) + クリスタル(10×コンボ) + ニアミス(25×コンボ) + ゾーン突破ボーナス。
- 650m ごとに SUNSET → NEON NIGHT → DAWN と景色が変わる。

## 特殊ゾーン（5種）

200m 以降、ランダムに発生してルールを一時的に書き換える。抜け切るとボーナス。

| ゾーン | 効果 | ボーナス |
|---|---|---|
| LOW GRAVITY | 重力 45%・ジャンプ初速 80%。滞空が長くなり、クリスタルが高所に出る | +300 |
| CRYSTAL RUSH | 障害物が一切出ない。クリスタルの波でコンボを一気に積む | +250 |
| GAUNTLET | 障害物の間隔が 68%（下限 0.60秒）。ひたすら weaving | +450 |
| MIRROR | 左右の操作が反転する | +400 |
| SPEED SURGE | 速度 1.3倍・距離スコア 2倍 | +350 |

障害物は **155m 手前で生成される**ため、ゾーンは「生成側」と「プレイヤー側」の2本のタイマーで
管理している。生成ルールを切り替えた 155m 後、その道がプレイヤーに届くのと同時にバナー・物理・
スコア倍率が発動する。分離しないと、バナーが出ている間ずっと前のルールの道を走ることになる。

LOW GRAVITY と GAUNTLET では**スライド用の障害物（青いバー）を出さない**。滞空が長い／間隔が
詰まった状態で「空中だと必ず当たる障害物」を混ぜると回避不能になるため、ジャンプで飛び越せる
赤い壁とレーン移動でかわす紫の柱だけに絞っている。

## デイリーミッション

- 日付（YYYYMMDD）をシードにした決定的な抽選で、**毎日3つ**のお題が出る。同じ日なら誰の端末でも同じ内容。
- お題は「1ラン単位」。ニアミス回数・距離・クリスタル・最大コンボ・スコア・ゾーン突破数の6種から
  易しい順に3つ選ばれる。
- 達成はリザルト画面で告知。3つ揃うと ALL CLEAR。

## アンロック（キツネ5種）

| 名前 | 解放条件 |
|---|---|
| SUNSET | 最初から |
| FROST | 累計距離 3,000m |
| NEON | ニアミス累計 100回 |

未解放のキツネをタップすると条件と現在の進捗が出る。

## バズり要素として入れたもの

- **ニアミス**：障害物をすれすれで抜けるとスローモーション＋ボーナス。切り抜きが映える瞬間を意図的に作っている。
- **リザルトカード**：1200×675 の PNG をその場で生成（Canvas 2D）。X にそのまま貼れるサイズ。`navigator.share` があればネイティブ共有、なければ画像長押し保存＋テキストコピー。
- **スマホ対応**：スワイプ操作、縦画面ではカメラを自動で引いて道幅を確保。
- **1プレイ 30〜60秒**：初見で理解でき、死因が常に自分のミスとして納得できる難易度カーブ。
- **特殊ゾーン**：1プレイの中身が毎回変わる。MIRROR や GAUNTLET は切り抜きが作りやすい。
- **デイリーミッション／アンロック**：明日また開く理由と、長期の収集目標。

## 実装メモ

- three.js r128（UMD / cdnjs）。マテリアルは `MeshPhongMaterial({flatShading:true})` で統一。
- 道路と地面はスクロールする **Canvas 2D 生成テクスチャ** 1枚ずつ。ジオメトリは各2三角形で、無限に続く道をほぼゼロコストで描いている。
- 障害物・クリスタル・ビル・パーティクルはすべてプール再利用（`Pool`）。実行中の new は発生しない。
- 当たり判定は軸ごとの「クリアランス」で計算し、`max(横のクリア, 縦のクリア)` が 0〜0.52 の範囲ならニアミス扱い。スライド高さは連続値で補間しているので、スライドが遅いほど判定がギリギリになる。
- **BGM・効果音とも WebAudio で合成。音声ファイルは1つも持たない**＝実況・配信で権利の問題が出ない。
  BGM は Am - F - C - G / 124BPM の4小節ループを16分音符ごとにスケジュールして鳴らしている
  （パッド・ベース・キック・ハイハット・アルペジオ＋ディレイ）。走行速度に連動して
  `inten` が上がり、フィルターが開いてドラムとアルペジオが乗る。
- 音声グラフは `sfx -> out -> destination` / `bgm -> out -> destination` の1本。
  ミュートは `out` のゲインを 0 にするので、**再生中の音も含めて即座に止まる**。
- 保存は localStorage の `polyrun.*`（`best` / `muted` / `prof` / `daily`）。読み書きは try/catch で保護。
- `prefers-reduced-motion` で画面シェイク・スローモーション・パーティクル量を抑制。
