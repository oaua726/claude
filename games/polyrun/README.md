# POLYRUN

ブラウザで即遊べるローポリ無限ランナー。`index.html` 1ファイル完結（外部依存は three.js r128 の CDN のみ）。

## 遊び方

`games/polyrun/index.html` をブラウザで開くだけ。インストール不要、サーバー不要。

| 操作 | キーボード | タッチ |
|---|---|---|
| レーン移動 | ← → / A D | 左右スワイプ |
| ジャンプ | SPACE / ↑ / W | タップ・上スワイプ |
| スライド | ↓ / S | 下スワイプ |
| サウンド ON / OFF | M | 右下の SOUND ボタン（全画面で常時表示）|
| 一時停止 / 再開 | ESC・P（再開は SPACE / Enter も可）| 左下の PAUSE ボタン |

## ルール

- 3レーンの道を自動で前進する。障害物に1回でも当たったら終了。
- **赤い壁 → ジャンプ / 青いバー → スライド / 紫の柱 → レーン移動**。色で回避方法が決まる。
- クリスタルとニアミスでコンボが伸びる（最大 x10、3秒で切れる）。
- スコア = 距離(1/m) + クリスタル(10×コンボ) + ニアミス(25×コンボ) + ゾーン突破ボーナス。
- 650m ごとに SUNSET → NEON NIGHT → DAWN と景色が変わる。

## 特殊ゾーン（4種）

200m 以降、ランダムに発生してルールを一時的に書き換える。抜け切るとボーナス。

| ゾーン | 効果 | ボーナス |
|---|---|---|
| LOW GRAVITY | 重力 45%・ジャンプ初速 80%。滞空が長くなり、クリスタルが高所に出る | +300 |
| CRYSTAL RUSH | 障害物が一切出ない。クリスタルの波でコンボを一気に積む | +250 |
| GAUNTLET | 障害物の間隔が 68%（下限 0.60秒）。ひたすら weaving | +450 |
| SPEED SURGE | 速度 1.3倍・距離スコア 2倍 | +350 |

障害物は **155m 手前で生成される**ため、ゾーンは「生成側」と「プレイヤー側」の2本のタイマーで
管理している。生成ルールを切り替えた 155m 後、その道がプレイヤーに届くのと同時にバナー・物理・
スコア倍率が発動する。分離しないと、バナーが出ている間ずっと前のルールの道を走ることになる。

LOW GRAVITY と GAUNTLET では**スライド用の障害物（青いバー）を出さない**。滞空が長い／間隔が
詰まった状態で「空中だと必ず当たる障害物」を混ぜると回避不能になるため、ジャンプで飛び越せる
赤い壁とレーン移動でかわす紫の柱だけに絞っている。

## デイリーミッション

- 日付（YYYYMMDD）をシードにした決定的な抽選で、**毎日3つ**のお題が出る。同じ日なら誰の端末でも同じ内容。
- お題は「1ラン単位」。ニアミス回数・距離・クリスタル・最大コンボ・スコア・ゾーン突破数の6種から
  易しい順に3つ選ばれる。
- 達成はリザルト画面で告知。3つ揃うと ALL CLEAR。

## アンロック（キツネ5種）

| 名前 | 解放条件 |
|---|---|
| SUNSET | 最初から |
| FROST | 累計距離 3,000m |
| NEON | ニアミス累計 100回 |
| EMBER | 特殊ゾーン 25回クリア |
| GOLD | ベストスコア 8,000 |

未解放のキツネをタップすると条件と現在の進捗が出る。

## バズり要素として入れたもの

- **ニアミス**：障害物をすれすれで抜けるとスローモーション＋ボーナス。切り抜きが映える瞬間を意図的に作っている。
- **リザルトカード**：1200×675 の PNG をその場で生成（Canvas 2D）。X にそのまま貼れるサイズ。`navigator.share` があればネイティブ共有、なければ画像長押し保存＋テキストコピー。
- **スマホ対応**：スワイプ操作、縦画面ではカメラを自動で引いて道幅を確保。
- **1プレイ 30〜60秒**：初見で理解でき、死因が常に自分のミスとして納得できる難易度カーブ。
- **特殊ゾーン**：1プレイの中身が毎回変わる。GAUNTLET や SPEED SURGE は切り抜きが作りやすい。
- **デイリーミッション／アンロック**：明日また開く理由と、長期の収集目標。

## リトライ体験

ランナーゲームで一番効く中毒装置は「死んだ0.5秒後にもう走っていること」なので、そこを優先している。

- **即リトライ**：死亡演出中（0.28秒以降）に SPACE / Enter / R / タップでそのまま次の走行へ。
  リザルト画面を経由しなくていい。
- **走行結果は死亡した瞬間に確定**（`commitRun()`）。ベストスコア・累計スタッツ・デイリー達成・
  アンロック判定はすべてここで行うので、即リトライしても記録は一切失われない。
  リザルト画面（`renderResult()`）は表示専用。
- **シェア画像は遅延生成**。1200×675 の PNG は data URL で約1.1MB あり、以前は死ぬたびに
  必ず生成していた。いまはリザルト表示の 700ms 後に作り、リトライすればキャンセルされる。
  シェアを押したときは `ensureCard()` で即座に作ってから渡す。
- **死因を表示**。当たった障害物から `JUMP` / `SLIDE` / `DODGE` を判定する。
  あわせて「ベストまで あと ◯◯」も表示する。
- 助言の文面は**衝突した瞬間の状態から組み立てる**（`killCause()`）。障害物の種類だけで
  固定文を出すと、スライド中に赤い壁へ当たった人に「ジャンプで飛べた」と言うような、
  その瞬間には不可能だった操作を指示してしまう。判定しているのは次の4つ:
  - 空中だったか（`G.air`）— ジャンプ中はスライドできないし、紫の柱は跳び越せない
  - 上昇中か下降中か（`G.vy`）— 「ジャンプが遅かった」か「早かった」かが変わる
  - 直前にスライドを試みたか（押した時刻を記録。1フレーム遅れのスライドは `slideT` が
    十分上がる前に衝突するので、効果ではなく入力そのものを見る必要がある）
  - 隣のレーンが空いていたか（`laneWasFree()`）— 空いていればレーン移動も選択肢として出す

## 演出

走っている最中の情報量を、プレイの良し悪しに連動させている。

**コンボの段階変化** — `heat`（コンボ3〜8を 0→1 に正規化した値）が上がると、キツネに薄い残像が付き、
道路の縁のネオンが明るくなる。コンボが切れると `heat` は上がりの2倍の速さで抜けるので、
失った瞬間に画面から色が引く。残像は `rig` のクローン8体を使い回し、1体あたり不透明度の
書き換え1回で済むようにしている。

**ビート同期** — BGM は自前のシーケンサーなので、キックを鳴らす AudioContext 時刻が分かっている。
その時刻を `BEATS` に積み、描画側で `AC.currentTime` を追い越した分を取り出して脈を打たせる。
道路の縁・太陽・FOV がキックに合わせて動く。**減衰を先に掛けてから取り出す**のが要点で、逆順だと
取り出した直後にそのフレーム分の減衰が掛かり、ピーク値がフレームレート依存になる（24fps で 0.83、
60fps で 0.92）。

**ジャンプと着地の重み** — 離陸で縦に伸び、着地で落下速度に比例して潰れる（スクワッシュ&ストレッチ）。
着地時には路面に広がるダストリング、カメラの沈み込み、落下速度でボリュームが変わる着地音が出る。

## 一時停止

- 走行中のみ有効。ESC / P / 左下の PAUSE ボタンで停止し、RESUME・最初からやり直す・
  タイトルへ の3択。停止中はスコアと距離を表示する。
- **タブを離れると自動で停止する**（`visibilitychange` と `blur`）。裏に回っている間に
  死ぬことがない。復帰時は自動再開せず、本人の操作を待つ。
- **再開は 3・2・1 のカウントダウンを挟む**。押した瞬間に走り出すと、目を離していた分だけ
  理不尽に死ぬため。カウント中も世界は止まったまま。
- BGM は `hold()` / `unhold()` で止めて戻す。`step` を保持したままスケジューラだけ止めるので、
  再開時にループの途中から続く（`start()` は先頭に巻き戻るので使わない）。
- 実装上は `state='pause'` で `step()` の先頭から抜けるため、物理・生成・スコアが一切進まない。

## 入力バッファ

空中でのジャンプ／スライド入力を短時間保持し、着地した瞬間に消化する。

- ジャンプ 0.15秒、スライド 0.17秒。
- これが無いと「着地の100ms前に押したジャンプ」が黙って消え、ゲームに無視されたように感じる。
- バッファは時間制限付きなので、頂点付近で押した入力は着地前に失効する（勝手に跳び続けない）。

## 実装メモ

- three.js r128（UMD / cdnjs）。マテリアルは `MeshPhongMaterial({flatShading:true})` で統一。
- 道路と地面はスクロールする **Canvas 2D 生成テクスチャ** 1枚ずつ。ジオメトリは各2三角形で、無限に続く道をほぼゼロコストで描いている。
- 障害物・クリスタル・ビル・パーティクルはすべてプール再利用（`Pool`）。実行中の new は発生しない。
- **ビルは4種のシルエット**（板／セットバック／尖塔／看板付き）を、同じ6つの子メッシュの
  表示・非表示と変形だけで作り分ける。生成のたびに組み直さないので、尖塔でも板と同じコスト。
  - 窓は1枚のキャンバス（一部の窓をランダムに消灯）をビルごとに `clone()` して
    `emissiveMap` に使い、`repeat` を大きさに比例させて窓のサイズを揃えている。
    バイオームごとの `win` 色を `emissive` に入れるので、夜だけ強く光る。
  - 看板は屋上ビルボードと壁から突き出す縦看板の2種。**壁と平行に貼ると通り過ぎる一瞬しか
    見えない**ため、どちらも道路側へ少し振っている。
  - 尖塔の頂点の航空障害灯は全ビルで1枚のマテリアルを共有し、BGMの小節頭で明滅させる。
  - ビルの本数は増やしていない。本数を増やすとモバイルのフレームレートが目に見えて落ちる
    （実測で約12%）のに対し、シルエットの作り分けはほぼ無料。
- 当たり判定は軸ごとの「クリアランス」で計算し、`max(横のクリア, 縦のクリア)` が 0〜0.52 の範囲ならニアミス扱い。スライド高さは連続値で補間しているので、スライドが遅いほど判定がギリギリになる。
- **BGM・効果音とも WebAudio で合成。音声ファイルは1つも持たない**＝実況・配信で権利の問題が出ない。
  BGM は Am - F - C - G / 124BPM の4小節ループを16分音符ごとにスケジュールして鳴らしている
  （パッド・ベース・キック・ハイハット・アルペジオ＋ディレイ）。走行速度に連動して
  `inten` が上がり、フィルターが開いてドラムとアルペジオが乗る。
- 音声グラフは `sfx -> out -> destination` / `bgm -> out -> destination` の1本。
  ミュートは `out` のゲインを 0 にするので、**再生中の音も含めて即座に止まる**。
- 保存は localStorage の `polyrun.*`（`best` / `muted` / `prof` / `daily`）。読み書きは try/catch で保護。
- `prefers-reduced-motion` で画面シェイク・スローモーション・パーティクル量を抑制。
